# myATLAS client

React 18 + Vite + Tailwind. Scaffolded in **MY-08** (JC).

Brand colours to configure in `tailwind.config.js`:

| Token      | Hex       |
| ---------- | --------- |
| Deep Navy  | `#1B3A6B` |
| Warm Amber | `#E8A020` |
| Off-white  | `#F8F6F2` |

Target viewport is **375px** — a mid-range Android phone. Design mobile-first.
